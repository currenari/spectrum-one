# Spectrum One Hardware v0.1.0

This folder contains the KiCad design files for Spectrum One hardware release v0.1.0.

Contents include:
- Schematic
- PCB layout
- Custom symbols and footprints
- Fabrication outputs (Gerbers and drill files)

The Gerbers in hardware/v0.1.0/gerbers are the release fabrication set for this version.
